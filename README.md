# Laboratory-Escape-Room

## Description
This project implements a chemistry/laboratory-themed VR escape room for the MP1 of CS417. The environment features a themed setting with imported models and a physics-based interaction system where players must bypass three "gate" sockets within a 5-minute countdown. The scene incorporates a UI-driven progression system with a loss timer, a win condition scoreboard, and a dedicated start screen. Interactive elements include themed props with grab affordances, red herrings to increase difficulty, and hidden collectibles. A win celebration involving a "You Win" message and environment changes triggers upon successful escape.
